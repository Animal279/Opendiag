## 6. 实现和验收约束

- 新增或修改页面/控件必须遵守[DS-01](ui-design-system.md)：共享主题 token、按钮角色、数据字体、分段/开关和表格密度；新增变体先补规范与公共实现，不复制页面私有色值/样式。
- UI 经 PageContext/Port/Application 获取业务能力，不直接 import Core/Adapters/Domain；耗时 IO 离开主线程，见[架构](architecture.md)及[线程规范](thread-model.md)。
- 接收到完整原参照前可以推进结构和已知交互，记录未核对的值；不为缺少原图标设计替代图标后宣称原样复刻。
- 每个可见控件、默认值、禁用条件、快捷键、错误提示和持久化行为都需对应规格行。原文未列全时保持待补，不删页面或忽略复杂状态。
- 页面功能、交互与视觉三个进度分开登记。只有文字结构或模拟交互完成，F17 仍不能标“已验收”。
- 视觉及相关真实业务证据依[测试策略](testing.md)登记；得到新材料后同时更新本表、需求状态和资源接收记录。
